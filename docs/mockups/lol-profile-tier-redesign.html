06 — 구현

기존 코드에 어떻게 얹는가

새 API도 새 색도 만들지 않습니다. 화면에 없던 값은 전부 이미 응답에 들어 있습니다.

추가로 표시하는 값은 모두 기존 응답에 있습니다. 승/패 실수치는 LolRankedStats.wins / losses, 소환사 레벨은 PublicLolProfile.summonerLevel, 갱신 시각과 쿨다운은 fetchedAt · refreshAvailableAt, LP 추이는 rankHistory: LolRankHistoryPoint[], 주 포지션은 roleAnalysis.mainRole, 주력 챔피언은 championPerformance입니다. 전적 리스트 때와 달리 서버 변경이 필요 없습니다.

접근성

  • 큐 세그먼트 — role="group" + aria-pressed. 전환 시 티어 패널을 aria-live="polite"로 안내합니다.
  • 티어 색 단독 의존 금지 — 크레스트 색과 별개로 티어 이름 문자가 항상 함께 있습니다. 언랭크는 회색 + "언랭크" 문자.
  • 승률 도넛 — 도넛은 aria-hidden, 옆의 "322승 263패 · 승률 55%" 텍스트가 값을 전달합니다.
  • 탭 — 기존 role="tab" 구조를 유지한 채 히어로 카드 하단으로 위치만 옮깁니다.
  • 대비 — 티어 색은 #1a2130 위에서 4.5:1 이상인 값만 씁니다. 어두운 iron/bronze 는 텍스트가 아니라 크레스트에만 씁니다.

i18n

  • 추가 키: profileSummonerLevel, profileMainRole, profileTopChampions, rankQueueSwitcher, rankRecordWinLoss, rankNextTierGap, rankUnrankedPlacement, profileFetchedAgo.
  • "승 / 패"는 일본어에서 勝 / 敗. 숫자와 붙여 쓰므로 폭이 유지됩니다.
  • 티어 이름은 Riot 공식 표기를 그대로 씁니다(한국어도 Grandmaster). 번역하지 않습니다.
  • "챌린저 컷까지 264 LP"는 Master 이상에만 쓰고, 그 아래는 "승급까지 N LP"로 문구가 갈립니다 — 키를 분리합니다.
