현재 전적검색 화면의 문제를 항목별로 진단하고, 사용자의 편의성과 가독성을 기준으로 재구성한 목업입니다. 데스크톱·모바일 레이아웃, 로딩/빈/오류 상태, 그리고 적용해야 할 기존 design token까지 함께 정리했습니다.

01 — 진단

지금 화면에서 무엇이 읽기 어려운가

라이브 서비스의 실제 프로필 화면(Grandmaster 계정, 10경기)을 기준으로 관찰한 항목입니다. 각 카드의 아래 칸이 이 목업에서 적용한 해결책입니다.

06 — 구현

기존 코드에 어떻게 얹는가

새 API도, 새 색도 만들지 않습니다. 목업의 모든 색·간격·모션 값은 styles/foundation/*.css에 이미 있는 토큰입니다.

팀 구성 컬럼은 API 변경 없이 가능합니다. PublicLolRecentMatch에 이미 teams: PublicLolMatchTeamDetail[]가 포함되어 10명 전원의 챔피언·Riot ID가 목록 응답에 들어옵니다. 현재는 펼침 패널에서만 쓰고 있어, 요약 행에서 렌더링만 추가하면 됩니다. opponent 필드도 같은 이유로 라인 상대 표시에 바로 쓸 수 있습니다.

접근성

  • 색 단독 의존 제거 — 승/패를 스트라이프·배경 틴트에 더해 승 / 패 문자 배지로도 표시. 등급 배지는 색과 별개로 문자(S+/A/B)가 값을 전달합니다.
  • 텍스트 대비 — 보조 텍스트를 #8492a8에서 #aebacc로 올려 #1a2130 위에서 4.5:1 이상 확보.
  • 펼침 버튼 — aria-expanded + aria-controls, 라벨은 “N번째 경기 상세 펼치기”로 순서를 포함.
  • 필터 칩 — role="group" + aria-pressed, 결과 변경은 aria-live="polite" 요약 문장으로 안내.
  • reduced motion — 펼침 애니메이션과 스켈레톤 shimmer 모두 prefers-reduced-motion에서 중지.

i18n

  • 신규 문구는 public-lol-i18n.ts에 한국어·일본어를 함께 추가합니다.
  • 추가 키: matchFilterQueueChips, matchSummaryStrip, matchTeamColumnLabel, matchStatKillParticipation, matchStatDamageShare, matchLobbyAverageTier, matchEmptyFiltered, matchLoadError.
  • 일본어는 조사 길이가 길어 지표 라벨이 2줄이 되기 쉽습니다. 라벨 폭을 min-width로 잡지 말고 text-overflow: ellipsis + title로 처리합니다.
  • “승 / 패” 배지는 일본어에서 勝 / 敗로 치환 — 1글자 폭이 유지되어 레이아웃이 흔들리지 않습니다.
